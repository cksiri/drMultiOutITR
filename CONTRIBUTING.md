# Contributing to drMultiOutITR

When the public repository is available, report bugs and suggestions at
https://github.com/cksiri/drMultiOutITR/issues. For a useful report, include the
package and R versions,
relevant settings, a short description of the expected and observed behavior,
and a reproducible example using **synthetic** data.

Do not attach patient-level information, confidential study datasets, fitted
models containing participant information, credentials, or private file paths.
The repository is for statistical software, not clinical decision support.

Changes to estimation methods or treatment ranking should be accompanied by
focused tests and a clear explanation of their statistical implications.
Documentation fixes can be submitted separately from algorithm changes.
